# KELUARGAKU

PWA standalone untuk pohon keluarga, silsilah, data kerabat, dan riwayat kesehatan keluarga.

- Tidak bergantung pada Hatchable.
- Tidak memakai server/database cloud.
- Data tersimpan lokal di browser/perangkat.
- Dapat bekerja offline setelah pertama kali dibuka.
- Cadangan data menggunakan Ekspor JSON.
- Jangan menyimpan data kesehatan di repository GitHub.

## GitHub Pages
Aktifkan Settings > Pages > Deploy from a branch > main > / (root).
URL umumnya: https://madeadja2026-sys.github.io/KELUARGAKU/

## Instal di Android
Buka URL HTTPS di Chrome Android, lalu pilih Install app atau Tambahkan ke layar utama.
